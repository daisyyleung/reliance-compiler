# Telemetry index

This folder is for generated run logs, evaluation summaries, metrics, and
observational reports. Telemetry is non-authoritative unless an explicit human
decision promotes a finding into current architecture or policy documentation.

No telemetry is retained for the initial build. Executable fixtures live in
`../evals/`; their results must be labelled `fixture_suite` and must not be
presented as production reliability or an SLO guarantee.
