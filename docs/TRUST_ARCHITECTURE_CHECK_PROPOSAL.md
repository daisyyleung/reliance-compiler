# Proposed Architect extension

For consequential agent projects, a future `TRUST ARCHITECTURE CHECK` should
require an evidence source and contract, load-bearing claims, assumption
handling, authority owner, action impact and reversibility, human and
independent verification gates, post-action verification, audit/state owner,
failure behaviour, reliance metric, and verification budget. If controls are
omitted, the Architect should report `TRUST ARCHITECTURE: INCOMPLETE`.

This is a proposal only; it does not modify the existing Agent Capability
Architect repository.
