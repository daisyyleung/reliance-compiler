# Differentiation

Reliance Compiler is a human-verification optimisation layer. It does not
produce a trust score, generic hallucination verdict, security review,
repository cleanliness report, approval token, or autonomous action. Its unit
of reasoning is the evidence-bound claim and its optimisation target is the
smallest safe verification set. Partial reliance, explicit assumptions, open
contradictions, and ordinal burden are first-class output rather than hidden in
a single confidence number.
