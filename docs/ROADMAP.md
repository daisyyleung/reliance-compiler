# Roadmap

## v0.1 (current)

Portable skill, machine contracts, deterministic checks, bounded planner,
receipts, comparison, shadow-audit schema, and counterfactual fixture suite.

## Phase 2 (documented only)

Build `agent-trust-layer` for “What Needs Me?”, policy enforcement, human review,
reliance ledger, shadow sampling, delegation levels, and post-action
verification. Initial vertical is email; boundary is READ, CLASSIFY, DRAFT with
no autonomous sending.

## Later research

Calibrate cost bands with observed review traces, add richer policy adapters,
independent verification interfaces, and longitudinal reliance regression
analysis. Do not add numeric confidence until an evidence-backed calibration
method exists.
